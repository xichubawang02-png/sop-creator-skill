## 当次 SOP 的记录表

每项记录：精确链接｜检索时间｜文件/提交标识｜许可证状态｜为何选用｜输入｜输出｜实际运行方式｜结果｜未验证项。

一个明确的描述比“全流程已跑通”有价值：
> 使用预装工具执行我新写的背板示例并导出 STL；还没有切片、打印和尺寸适配，因此仅证明几何导出流程可运行。

禁止把计划使用某技能写成已安装，把原文阅读写成代码实测，把出图写成商业验证。来源失效时提供原生替代方案与限制，不为补齐表格编造仓库。
